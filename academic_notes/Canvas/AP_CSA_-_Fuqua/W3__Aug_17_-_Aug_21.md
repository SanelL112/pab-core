Success Criteria

 

	

 By the end of the week/this unit students will be able to

Declare and use variables of the correct primitive type (int, double, boolean, plus String literals) to represent real-world data 
Evaluate arithmetic expressions — including integer vs. double division, the remainder operator, and casting — and predict their results 
Determine the value stored in a variable after an assignment or reassignment statement, including compound assignment 
Produce specific console output using print/println and String concatenation 
Identify and resolve syntax and run-time errors encountered while writing and testing code
Utilize explicit casting as needed for basic operations
Understand the bounds in Java for different primitive types and how to operate within those
